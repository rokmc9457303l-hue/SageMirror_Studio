# 채널 정체성 유지 규칙 (CHANNEL_IDENTITY)

> 이 파일은 모든 Part 실행 시 `load_prompt()`가 자동 주입한다.  
> Profile YAML이 최우선이며, 이 파일은 기본 원칙을 제공한다.

---

## 1. Profile 강제 적용

| Profile 필드 | 적용 방식 |
|---|---|
| `channel_name` | 모든 결과물 헤더에 반영 |
| `target_audience` | 어휘 수준·예시 자동 조정 |
| `tone` | 문체 일관성 유지 |
| `core_symbols` | 시각 모티프 통일 (이미지 프롬프트 반영) |
| `forbidden_expressions` | 절대 사용 금지 |
| `preferred_expressions` | 적극 활용 |
| `philosophy_anchor` | 인용·해석의 지식 기반 |
| `narrator_style` | 내레이터 톤·어조 기준 |

---

## 2. 이전 영상 참조 (자동 RAG)

- 옵시디언 `채널_{채널명}/` 에서 이전 에피소드 최대 5편 자동 RAG
- 중복 주제 자동 감지 → 회피 (동일 키워드 70% 이상 겹치면 경고)
- 이전 영상의 어조·문체 패턴 학습 → 일관성 유지
- 댓글 피드백 누적 자료 (`Part1_자료수집/`) 자동 참조

---

## 3. 채널 진화 원칙

- 댓글 피드백 → 다음 영상 기획에 반영
- 떡상한 영상 패턴 → 자동 추출 → 다음 기획 반영
- 실패한 영상 패턴 → 회피 목록 누적

---

## 4. 결과물 일관성 체크포인트

모든 Part 결과물이 다음을 준수하는지 Critic이 자동 검증:

```
✅ 채널명이 결과물에 일관되게 반영됨
✅ forbidden_expressions 사용 없음
✅ 타겟 시청자 어조에 부합함
✅ 철학·지식 기반이 philosophy_anchor와 일치함
✅ 시각 요소가 core_symbols와 일관됨
```

---

## 5. 에피소드 간 연속성

- 각 에피소드는 독립적이지만 채널 색깔은 동일
- `current_episode` 상태로 에피소드 번호 추적
- 옵시디언 `채널_{채널명}/` 하위에 에피소드별 서브폴더 생성
