# 출처 표기는 선택이 아니다

이 시스템에서 사실을 주장하는 모든 문장은 출처가 있어야 한다.
출처 없으면 사실 아님. 사실 아니면 영상에 들어갈 수 없다.

---

# 표기 형식 7가지

## 1. YouTube 댓글

```
[SOURCE: youtube_comment_id_xxxxxx]
또는
[SOURCE: youtube_video_id_xxx_comment_N]
```

예시:
```
시청자의 65%가 "참다가 떠났다"고 말한다 
[SOURCE: youtube_comment_analysis_video_abc123]
```

## 2. 옵시디언 저장 자료

```
[SOURCE: schema_id_SRC_yyyymmdd_hhmmss]
```

예시:
```
관계 상처는 노년의 외로움으로 이어진다 
[SOURCE: schema_id_SRC_20260614_153022]
```

## 3. Tavily 웹 검색

```
[SOURCE: tavily_url_https://...]
```

예시:
```
한국 노인의 35.3%가 우울증 위험군 
[SOURCE: tavily_url_https://kostat.go.kr/2024-elderly-report]
```

## 4. 책 / 문헌

```
[SOURCE: book_저자_제목_p페이지]
```

예시:
```
"인생은 진자처럼 고통과 권태 사이를 오간다" 
[SOURCE: book_쇼펜하우어_의지와표상으로서의세계_1권_§57]
```

## 5. 성경 / 경전

```
[SOURCE: bible_책_장:절]
[SOURCE: classic_저자_편명]
```

예시:
```
"내가 사망의 음침한 골짜기로 다닐지라도..." 
[SOURCE: bible_시편_23:4]

"학이시습지면 불역열호아" 
[SOURCE: classic_공자_논어_학이편]
```

## 6. 사용자 직접 입력

```
[SOURCE: user_input]
```

예시:
```
이 채널의 핵심 주제는 '고독한 자기 직면'이다 
[SOURCE: user_input]
```

## 7. AI 추론 (사실 아님 명시)

```
[INFERENCE: 추론 근거]
```

예시:
```
이 패턴은 4070세대에게 더 흔할 가능성이 있다 
[INFERENCE: 댓글 200개 중 평균 연령 추정 + 일반적 심리 통계]
```

# 출처 우선순위

같은 사실에 여러 출처 가능 시 우선순위:

```
1순위: 실제 댓글 (가장 강력한 근거)
2순위: 출판물 / 학술 자료
3순위: 신뢰할 수 있는 웹 자료
4순위: 옵시디언 누적 자료
5순위: 사용자 입력
6순위: AI 추론 (마지막 수단)
```

---

# 위치 규칙

태그는 해당 주장 **직후**에 위치:

```
✅ "65%가 후회한다 [SOURCE: ...]. 이는 ..."
❌ [SOURCE: ...] "65%가 후회한다." (위치 잘못)
❌ "65%가 후회한다. ... 다른 내용 ... [SOURCE: ...]" (너무 멀리)
```

---

# 다중 출처

여러 출처가 한 주장을 뒷받침할 때:

```
이 패턴은 동서양에서 공통적으로 발견된다 
[SOURCE: book_융_인격과무의식_p47][SOURCE: bible_시편_42편]
```

쉼표 없이 연속 표기. 최대 3개까지.

# 사실 vs 의견 구분

## 사실 (출처 필수)

```
- 통계, 수치
- 인명, 책 제목, 페이지
- 날짜, 사건
- 인용문
- 채널 정보
- 댓글 인용
```

## 의견 (출처 불필요, 단 의견임을 명시)

```
✅ "이런 영상이 시청자에게 깊은 울림을 줄 수 있다 [의견]"
✅ "이 주제는 채널 톤과 잘 맞는다고 판단된다 [판단]"
```

## 보편적 진리 (출처 불필요)

```
✅ "사람은 누구나 한 번은 죽는다"
✅ "1년은 365일이다"
```

# 검증 가능 여부

출처는 검증 가능해야 한다:

```
✅ 검증 가능
- YouTube 영상 ID + 댓글 위치
- 책 제목 + 정확한 페이지
- URL (접속 가능)
- 옵시디언 파일 경로

❌ 검증 불가능
- "어디서 본 것 같다"
- "옛날에 읽은 책에서"
- "누가 그랬는데"
- "들은 적이 있다"
```

# Critic 자동 검사

모든 결과물에서 다음 자동 검사:

```python
# 1. 수치 있는데 출처 없음
if has_number(text) and not has_source_tag_nearby(text):
    flag("출처 없는 수치")

# 2. 인용문(따옴표) 있는데 출처 없음
if has_quote(text) and not has_source_tag_nearby(text):
    flag("출처 없는 인용")

# 3. 인명 + 발언 있는데 출처 없음
if has_person_quote(text) and not has_source_tag_nearby(text):
    flag("발언 출처 없음")
```

플래그 발생 시 → NEEDS_DATA → Scout 호출

# 출처 미상 시 행동

찾으려고 했는데 출처를 못 찾을 때:

```
1순위 행동: 해당 주장 삭제
2순위 행동: "[추정]" 명시
3순위 행동: "[INFERENCE: ...]" 추론으로 격하
```

**절대 임의로 출처를 만들어내지 말 것.**

