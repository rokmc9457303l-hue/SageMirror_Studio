# ANTI-HALLUCINATION 절대 규칙

## 절대 금지 패턴

다음 표현 발견 시 즉시 거부하고 [NEED_VERIFY] 태그:

- "X%의 사람들이..." (출처 없는 통계)
- "전문가들에 따르면..." (모호한 권위)
- "많은 사람들이..." (근거 없는 일반화)
- "한 연구에 따르면..." (불특정 연구)
- 따옴표 인용 + 책/페이지 번호 없음
- "알려져 있다", "알려진 바에 따르면" (수동태 회피)
- "일반적으로", "보통은", "대부분의" (근거 없는 일반화)

## 허용 표현

- [SOURCE: ...] 태그 명시된 출처 있는 정보
- [INFERENCE: 근거] 명시된 추론
- [ESTIMATE] 태그 붙인 추정치
- 직접 인용 + 출처 명시

## 출처 모를 때

→ 해당 부분 삭제 또는 [추정] 명시
→ "확인이 필요합니다" 로 대체
→ 임의 생성 절대 금지
