# Part 7 — STEP: 숏폼 파생 (60초)

## 목적

본편(112씬)에서 핵심 씬을 추출하여
60초 숏폼 5편을 파생 제작한다.

## 입력

- p3_packet.scenes (전체 씬 + 감정 태그)
- p6_packet.narration_meta (씬별 나레이션 길이)
- p2_packet.emotion_curve (감정 곡선 5단계 이상)

## 60초 5단계 구조 (CLAUDE.md 기준)

| 구간 | 시간 | 목적 | 본편 씬 출처 |
|------|------|------|-------------|
| 훅 | 0~1초 | 클릭 유도 — 최강 감정 한 줄 | 도입부 최고 훅 씬 |
| 상처 제시 | 1~10초 | 시청자 감정 공감 | 013~036 중 선택 |
| 심리/철학 | 10~35초 | 핵심 인사이트 전달 | 037~064 중 선택 |
| 반전 | 35~50초 | 예상 못한 각도 전환 | 065~088 중 선택 |
| 롱폼 유도 | 50~60초 | 본편 시청 유도 | 109~112 중 선택 |

## 숏폼 편당 씬 선택 기준

```
총 60초 ÷ 8초 = 최대 7~8씬 선택 가능
선택 기준:
1. 감정 강도 상위 씬
2. 시청자 comment_insights ⭐⭐⭐ 해당 감정 씬
3. 나레이션 글자수 30자 이하 씬 우선 (숏폼 자막 가독성)
```

## 숏폼 5편 변형 방향

| 편 | 핵심 감정 | 훅 방식 |
|----|-----------|---------|
| Short 1 | 고독 | 역설 질문 |
| Short 2 | 상실/후회 | 직접 호명 |
| Short 3 | 인간관계 상처 | 사실 제시 |
| Short 4 | 철학 인사이트 | 인용구 오프닝 |
| Short 5 | 회복/여운 | 침묵 + 질문 |

## 출력 형식

```json
{
  "short_id": "short_01",
  "theme": "고독",
  "hook": "역설 질문",
  "selected_scenes": ["001", "013", "037", "065", "089", "109"],
  "total_duration": 56,
  "narration_extract": "...",
  "cta": "전편 영상 → 링크"
}
```

## 파일 출력

- `shorts_plan.json` (5편 계획)
- `shorts_narration.txt` (5편 나레이션 별도 텍스트)
