# Part 2 — STEP: 기획안 작성

## 입력

- p1_packet (topic, core_emotion, audience_pain, comment_insights)
- {{CHANNEL_NAME}} 채널 정체성

## 기획안 필수 항목

1. **최종 주제** — 한 문장 ({{TARGET_AUDIENCE}} 즉시 공감 유도)
2. **한 줄 핵심 메시지** — 영상 전체를 관통하는 철학적 한 줄
3. **시청자 페르소나** — 구체적 인물 설정 (나이/상황/고통)
4. **영상 포지셔닝** — 기존 영상과 차별화 지점
5. **대본 방향** — 필수 포함 / 절대 금지 목록

## 출처 연결

- p1_packet의 comment_insights 최소 3개 인용
- [SOURCE: comment_id_xxx] 태그 필수
- {{PHILOSOPHY_ANCHOR}} 기반 지식 연결 방향 명시

## 금지

- p1_packet 없는 상태 기획 금지
- {{FORBIDDEN_EXPRESSIONS}} 포함 금지
- "힐링", "성장", "도전" 류 긍정적 마무리 금지

## 출력

- 기획안 문서 (위 5개 항목 포함)
- → STEP_감정흐름.md로 전달
