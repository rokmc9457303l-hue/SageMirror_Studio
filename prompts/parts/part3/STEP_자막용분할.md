# Part 3 — STEP: 자막용 분할

## 목적

112씬 대본(STEP_대본작성.md 출력)을 자막 파일 형식으로 분리한다.
하나의 TALK 씬 나레이션이 길 경우 3~5줄로 쪼갠다.

## 입력

- p3_packet.scenes (scene_id, type, narration, duration=8)

## 분할 기준

| 조건 | 처리 |
|------|------|
| 한 씬 나레이션 ≤ 25자 | 1줄 자막 |
| 26~50자 | 2줄 분할 (의미 단위 기준) |
| 51자 이상 | 3줄 이상 (최대 4줄) |
| PAUSE / SILENT | 빈 자막 또는 `[침묵]` |
| ECHO | 이탤릭 처리 표기 `*텍스트*` |

## 분할 규칙

1. 조사 앞에서 줄 바꿈 (X에서 → X / 에서...)
2. 쉼표 뒤 자연스러운 지점 우선
3. 한 줄 최대 20자 권장
4. 부사구는 다음 줄 첫 단어와 함께

## 출력 형식

```
scene_id | sub_line_no | text | start_offset | end_offset
001 | 1 | "당신은 혼자입니까" | 0.0 | 4.0
001 | 2 | "아니면 혼자라고 느낍니까" | 4.0 | 8.0
002 | 1 | [침묵] | 0.0 | 8.0
```

## SRT 변환 규칙

- 씬 1개 = 8초 블록 (00:00:00,000 ~ 00:00:08,000)
- 2줄 자막: 각 4초
- 3줄: 첫 2줄 각 2.5초 + 마지막 3초
- 파일명: `subtitle_{scene_id}.srt`

## 품질 기준

- 1줄 최소 10자 (너무 짧은 줄 금지)
- 의미 단위 유지 (동사-목적어 분리 금지)
- 금지: 조사만 다음 줄로 이동
