# Part 3 — STEP: 대본 작성

## 대본 작성 원칙

- 화자: {{TONE}} 기준의 나레이터 ({{NARRATOR_STYLE}})
- 가르치지 않음 — 함께 바라봄
- 직접 체험 고백 형식 권장
- 감정 곡선 (p2_packet.emotion_curve) 준수

## 씬별 대본 형식

```
[씬 001] TALK | 감정: 고독
나레이션: "..."
BGM: [큐시트 참조]
이미지: [asset_id 또는 설명]
```

## 표현 기준

**필수 포함:**
- {{PHILOSOPHY_ANCHOR}} 기반 인용 (출처 명시)
- 시청자 감정 직접 호명 ("당신은...", "우리는...")
- 침묵·여운 씬 (PAUSE/SILENT) 적절 배치

**절대 금지:**
- {{FORBIDDEN_EXPRESSIONS}}
- 해결책 제시 (상처를 위로하는 결론 금지)
- AI 냄새 표현 (물론, 그렇기 때문에, 중요한 점은)

## 지식 인용 형식

- `[성경: 책 장:절 — 내용]`
- `[철학: 저자 — 출처 — 인용구]`
- [NEED_VERIFY] 태그: 출처 불명 시 즉시 표기

## 출력

- 112씬 대본 (씬별 나레이션 + 타입 + 감정태그)
