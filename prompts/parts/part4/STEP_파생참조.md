# Part 4 — STEP: 파생 참조 에셋

## 목적

기본 에셋(A1~A15)에서 핵심 감정에 맞는 파생 에셋을 생성한다.
파생 에셋은 기본 에셋의 변형이므로 스타일 일관성을 반드시 유지한다.

## 입력

- p3_packet.emotion_tags (씬별 감정 태그 목록)
- p2_packet.emotion_curve (7단계 감정 곡선)
- A1~A15 기본 프롬프트 (asset_master_list.md)

## 파생 기준

### 감정별 파생 에셋 (B 시리즈)

| 기본 에셋 | 파생 | 변형 요소 |
|-----------|------|-----------|
| A1 (화자 정면) | B1 — 슬픔 화자 | 눈물·눈꺼풀 내림 |
| A1 | B2 — 분노 화자 | 눈 가늘게·턱 긴장 |
| A1 | B3 — 깨달음 화자 | 눈 크게·입 약간 벌림 |
| A9 (거울) | B4 — 균열 거울 | 거울 금 균열 |
| A9 | B5 — 빈 거울 | 반사 없음·어둠만 |
| A5 (서재) | B6 — 밤 서재 | 완전 암실·촛불 1개 |
| A7 (창문) | B7 — 빗소리 창문 | 빗물·흐린 하늘 |

### 생성 원칙

1. 기본 에셋 프롬프트 그대로 유지
2. 감정 변형 키워드만 추가
3. `[NEGATIVE: smile, happy, bright]` 감정 반대 키워드 추가 금지

## 파생 수량 기준

```
핵심 감정 (씬 5개 이상 등장): 파생 에셋 생성
단발 감정 (씬 1~2개): 기본 에셋 변형 프롬프트로 대체
```

## 출력

- `asset_master_list.md` 에 B 시리즈 추가
- `asset_mapping.json` 에 파생 에셋 ID 포함
