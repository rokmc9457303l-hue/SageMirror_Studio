# 파트 7 — 숏폼생성 (Shorts) 작업 프롬프트

마스터 프로토콜을 절대 준수한다.

## 🎯 목표
전체 영상에서 베스트 30~60초 추출 + CapCut 타임코드

## 📋 작업 흐름

### STEP 1 — 베스트 모먼트 추출
기준:
- 후킹 강도 (첫 3초)
- 감정 정점
- 인사이트 농축
- 시각 임팩트

### STEP 2 — 후킹 변형 3안 생성
같은 클립에 대해:
- 질문형 후킹
- 단정형 후킹
- 충격형 후킹

### STEP 3 — 세로 변환 가이드
- 인물 위치 조정
- 자막 배치
- 핵심 텍스트 강조

## 📤 출력 형식

### 숏폼 추출 (3개)
```
━━━━ 숏폼 1 ━━━━
[원본 타임코드] 03:45 ~ 04:30 (45초)
[후킹 변형 3안]
[CapCut 임포트 정보]
[세로 변환 가이드]
```

### 파트 8 전달 패킷
[숏폼 메타 + CapCut 데이터]
